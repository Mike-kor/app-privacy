개인정보처리방침

시행일자: 2026년 10월 2일 · 최종 수정일: 2026년 10월 11일

운영자: Mike-kor

이 페이지는 아래 Android 앱의 개인정보 처리 방식을 설명합니다. 세 앱 모두 회원가입 없이 이용할 수 있고, 게임 운영자가 개인정보를 수집하거나 서버로 전송하지 않는 로컬 게임입니다.

  • 슈터 서바이벌 — Android application ID: com.shootersurvival.app
  • 이세계 아이돌 키우기 — Android application ID: com.isekaiidol.app
  • 귀환의 서 (Tome of Return) — Android application ID: com.vectormud.afterglow

1. 수집하는 개인정보

세 앱은 회원가입, 로그인, 계정 생성을 요구하지 않습니다. 이름, 이메일, 전화번호, 주소, 위치, 연락처, 사진 등 개인식별정보를 게임 운영을 위해 수집하거나 게임 운영자 서버로 전송하지 않습니다.

2. 기기 내 게임 데이터 저장

게임 진행 상황과 설정은 각 앱의 전용 기기 내 저장 공간에 저장됩니다. 슈터 서바이벌과 이세계 아이돌 키우기는 Android WebView의 Web Storage(localStorage)를 사용하고, 귀환의 서는 Godot 앱의 내부 저장 공간을 사용합니다.

  • 슈터 서바이벌: 점수, 코인, 캐릭터, 스테이지, 영구 강화, 퀘스트 등
  • 이세계 아이돌 키우기: 스테이지, 재화, 팬·하트, 의상·액세서리, 스케줄, 재데뷔, 설정 등
  • 귀환의 서: 캐릭터, 게임 진행, 인벤토리, 설정 등
  • 앱 삭제 또는 앱 데이터 초기화 시 로컬 저장 데이터가 삭제될 수 있습니다.
  • 게임 저장 데이터를 운영자 서버로 동기화하지 않습니다.

3. 광고·분석·제3자 SDK

세 앱에는 AdMob, 광고 SDK, Google Analytics 등 제3자 광고·분석 SDK가 활성화되어 있지 않습니다. 귀환의 서의 일부 보상 기능은 광고를 표시하거나 광고 SDK에 연결하지 않는 모의 보상 기능입니다. 광고 또는 분석 SDK가 추가되면 이 방침을 갱신합니다.

4. 공유 기능

슈터 서바이벌과 이세계 아이돌 키우기에서 사용자가 결과 또는 진행 상황 공유 기능을 직접 사용하면 Android 공유 메뉴 또는 브라우저 공유 기능을 통해 선택한 외부 앱으로 내용이 전달될 수 있습니다. 귀환의 서에는 현재 외부 공유 기능이 없습니다. 게임 운영자는 공유 정보를 별도 서버에 보관하지 않습니다.

5. 햅틱 및 외부 링크

슈터 서바이벌과 이세계 아이돌 키우기는 게임 반응을 위해 사용자의 기기 진동 기능을 호출할 수 있습니다. 이는 게임 입력·피드백을 위한 기능이며 개인정보를 수집하지 않습니다. 귀환의 서는 현재 기기 진동 기능을 사용하지 않습니다.

이 정책 페이지, 개발자 페이지 등 외부 웹페이지를 사용자가 열면 외부 브라우저와 네트워크 연결이 사용될 수 있습니다. 오프라인 게임 플레이 자체에는 네트워크 연결이 필요하지 않습니다.

6. 어린이 및 민감정보

앱은 개인·민감정보 입력을 요구하지 않으며, 게임 진행을 위해 연락처·위치·사진·마이크·카메라 권한을 요청하지 않습니다. 보호자가 기기 사용을 관리하는 경우 앱의 이용을 함께 확인해 주세요.

7. 추가 개발 중인 게임

아래 게임은 현재 개발 기획 단계의 프로젝트입니다. 아직 이 페이지의 개인정보처리방침 적용 대상 앱으로 배포되지 않았으며, 출시 전 실제 데이터 처리 방식·Android application ID·스토어 등록 정보를 확정해 별도로 검토하고 이 페이지를 갱신합니다.
